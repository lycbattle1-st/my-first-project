# 个人介绍网站

这是一个不需要安装任何软件的静态网站模板。双击打开 `index.html` 就能在浏览器预览。

## 你需要替换的内容

在 `index.html` 中搜索并依次替换这些文字：

- `你的名字`
- `你的职业或专长`
- `你的城市`
- 三段工作经历（职位、公司、年份、成果）
- 三个代表项目（项目名称、你的角色、成果）
- `your@email.com`
- LinkedIn、公众号或其他社交主页链接

## 上传到 GitHub

1. 打开你的仓库：<https://github.com/lycbattle1-st/my-first-project>。
2. 点击 **Add file** → **Upload files**。
3. 把本文件夹里的 `index.html`、`style.css`、`script.js` 和 `README.md` 一起拖进页面。
4. 点击绿色的 **Commit changes** 按钮保存。

下一步可在仓库的 **Settings** → **Pages** 中免费发布为可访问的网站。上传完成后，请把仓库链接发给我，我会继续带你发布它。
